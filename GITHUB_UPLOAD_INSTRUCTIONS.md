# Upload to GitHub: jimkliew

1. Sign in as `jimkliew` at https://github.com/new.
2. Create a repository named `wall-street-2.0-lecture` (or use another name and adjust the URL).
3. Unzip the downloaded package. Upload **all files and folders inside** `Wall_Street_2_Agentic_FX_GitHub_Upload` to the repository root. Do not upload only the ZIP.
4. Commit the files to the `main` branch.
5. Go to **Settings → Pages**; select **Deploy from a branch**, `main`, `/ (root)`; save.
6. Your student website should be at: `https://jimkliew.github.io/wall-street-2.0-lecture/` once Pages deploys.
7. Students can download the `.pptx` from the website header, run the simulator, explore the Python source, and take the five-question decorator quiz.
