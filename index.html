WHY THIS MATTERS
The trusted-services boundary
The AI agent may request a trade, but only authenticated tools and deterministic rules can approve it.

     

     
POLICY OWNERSHIP AND ENFORCEMENT
Two agents. Two sets of rules. Both must pass.
Policy owners approve the business limits. Trusted services enforce them in code. A system prompt can describe the limits, but it does not substitute for a policy engine.

2. VERSIONConfiguration + code release
→
3. ENFORCEBoth policy checks on every call
→
4. AUDITRecord approval or rejection

      
Failure example: A Hyundai agent can say “I approve $600,000,” or a fake JPMorgan agent can post a quote to a public board. Neither message grants permissions. The policy layer checks identity, amount, currency, account, quote validity, and idempotency before any simulated settlement.
